# Комплекс лабораторных работ по ГМСАПР (C++ / OpenGL)

Данный репозиторий содержит две независимые лабораторные работы, посвященные работе с двумерной растровой графикой (обработка изображений) и трехмерными сценами (симуляция звездной системы).

---

## 📦 Готовые сборки (Releases)
Если вы хотите протестировать работу приложений без настройки среды разработки и компиляции кода, перейдите в раздел **Releases** в правой панели репозитория:
- В релизе `lab2` доступен ZIP-архив со скомпилированным EXE-файлом **Lab2_Filters**.
- В релизе `lab3` доступен ZIP-архив со скомпилированным EXE-файлом **Lab3_SolarSystem**.

## 🛠️ Зависимости для самостоятельной сборки
Для компиляции исходного кода обеих лабораторных работ требуются следующие внешние библиотеки:
- **GLFW** — управление окнами и контекстом OpenGL.
- **GLAD** — загрузчик функций OpenGL Core Profile.
- **GLM** — математическая библиотека матричных операций (для Лабораторной №3).
- **Dear ImGui** — библиотека графического интерфейса (для Лабораторной №2).

## 🖼️ Лабораторная работа №2: Редактор изображений (CAD Image Filters)

Графическое интерактивное приложение на базе **Dear ImGui** для загрузки и фильтрации растровых изображений с использованием матриц свертки.

### Выполненные требования:
1. **Интерфейс на Dear ImGui:** Полноэкранный холст ("Main Canvas") с кнопкой выбора файла, переключателями (Radio Buttons) фильтров и кнопкой "APPLY FILTER".
2. **Загрузка изображений:** Интегрирована библиотека `stb_image` для безопасного парсинга файлов (PNG/JPG/JPEG). 
3. **Двухоконный просмотр (Сравнение):** Экран разделен на две адаптивные колонки, отображающие оригинальное изображение (слева) и обработанное (справа) с автоматическим сохранением пропорций сторон.
4. **Матричные фильтры:**
   - **Sharpen (Резкость):** Матричный фильтр усиления контуров.
   - **Emboss (Тиснение):** Сверточный фильтр выделения рельефа с использованием масштабирования коэффициентов (`scale`) и смещения цвета (`offset = 128.0f`) для создания серого эффекта подложки.
5. **Безопасная свертка с clamp:** Алгоритм свертки защищен от выхода цвета за пределы `[0; 255]` с помощью `std::clamp`, исключая артефакты переполнения типа данных.

## 🪐 Лабораторная работа №3: 3D Симулятор Солнечной Системы

Интерактивный трехмерный симулятор планетной системы с динамическим освещением и пасхалкой.

### Управление и интерактивная камера:
В проект интегрирована система свободной камеры, позволяющая перемещаться по трехмерному пространству космоса:
- **`W`, `A`, `S`, `D`** — перемещение камеры вверх, влево, вниз и вправо относительно направления взгляда.
- **Колесико мыши (Scroll)** — динамическое изменение угла обзора (Zoom / Фокусное расстояние) для приближения или отдаления объектов.

### Выполненные требования:
1. **Орбит и Вращение:** Реализовано круговое и эллиптическое движение планет, а также их собственное вращение вокруг своей оси.
2. **Точечное освещение (Ламберт):** Написан кастомный фрагментный шейдер. Освещение рассчитывается от центральной звезды, обеспечивая смену дня и ночи на поверхностях планет. Реализовано затухание (Attenuation) для удаленных объектов.
3. **Комета-источник света:** Добавлена пролетающая комета со своим зеленым спектром свечения, выступающая вторым независимым источником света на сцене.
4. **Адаптивный Viewport:** Реализована корректная обработка изменения размеров окна. При растягивании на весь экран пропорции планет динамически пересчитываются (`glViewport`), предотвращая их сплющивание.

### Архитектурные оптимизации:
- Попробуйте сделать двойнок клик в любом месте окна!
- **Кэширование юниформ (Uniform Caching):** Все локации переменных (`glGetUniformLocation`) вынесены из цикла `Render()` в этап инициализации. Обмен данными с GPU происходит напрямую по ID без посимвольного текстового поиска, что гарантирует высокий FPS.
- **Оптимизация RTTI:** Поиск кометы в цикле через тяжелый `dynamic_cast` заменен на O(1) кэширование указателя.
