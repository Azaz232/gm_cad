# 3D Симулятор Солнечной Системы (C++ / OpenGL 3.3)

Интерактивный симулятор Солнечной системы с динамическим освещением, текстурированием и скрытой пасхалкой.

## 🛠 Зависимости для сборки (или вы можете установить релизную версию проекта из Releases в https://github.com/Azaz232/gm_cad)
Для запуска проекта необходимы следующие библиотеки (вы можете установить их через любой менеджер пакетов, например `vcpkg`, или подключить вручную):
- **GLFW** (управление окном и вводом)
- **GLAD** (загрузчик функций OpenGL)
- **GLM** (математическая библиотека для матриц)

## 🚀 Выполненные требования ТЗ:
1. **Движение планет:** Реализовано вращение небесных тел вокруг своей оси и по круговым/эллиптическим орбитам.
2. **Точечное освещение:** Реализован расчет Lambertian-освещения от Солнца (дневная и ночная стороны планет). Добавлено затухание (attenuation) света для удаленных планет.
3. **Уникальные текстуры:** Каждое небесное тело имеет свою неповторяющуюся текстуру.
4. **Комета-источник света:** В систему добавлена пролетающая комета, которая имеет собственный зеленый спектр свечения и динамически освещает пролетаемые объекты.
5. **Адаптивный интерфейс:** Реализована корректная обработка изменения размеров окна (`glViewport` и динамический пересчет матрицы проекции) — планеты не сплющиваются при растягивании.

## 🐈 Пасхалка «Кошка Муся»
- Попробуйте сделать двойной клик левой кнопкой мыши (LMB) в любой точке экрана.

## ⚡️ Произведенные оптимизации (Дополнительно):
- **Юниформ-кэширование:** Все локации юниформ (`glGetUniformLocation`) вынесены из игрового цикла рендеринга в этап инициализации сцены (`CacheUniforms`). Данные передаются напрямую по ID, что исключает затратный посимвольный поиск строк на GPU 60+ раз в секунду.
- **Оптимизация RTTI:** Из цикла рендера полностью удален тяжелый оператор `dynamic_cast` для поиска кометы. Ссылка на комету кэшируется в O(1) при создании.
